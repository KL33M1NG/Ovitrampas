# 🦟 Mapa de Ovitrampas - Vigilancia del Dengue

Aplicación web para registrar y visualizar puntos de ovitrampas mediante un mapa de calor, con almacenamiento online en Google Sheets.

## ✨ Funcionalidades
- 📍 Registro de puntos por latitud/longitud con nombre
  - 🔥 Mapa de calor según cantidad de casos
- 📋 Pestaña separada con todos los registros (tabla)
  - ☁️ Guardado online en Google Sheets (compartido entre usuarios)
- 🔍 Filtros por nombre, fecha (desde/hasta), casos mínimos y nivel de riesgo
  - 💾 Respaldo local (localStorage) — funciona offline
- 📤 Exportar/Importar JSON
  - 📝 Exportar a PDF
- 📊 Exportar CSV (con filtros aplicados)
  - 🎨 Marcadores por color según riesgo: 🟢 bajo, 🟠 medio, 🔴 alto
- 📱 Diseño responsive
